# scRNAseq using Seurat

This is my independent single-cell RNA-seq (scRNA-seq) analysis using the Seurat package in R and a number of algorithms to prepare the data (SoupX, scrublet) and post processing such as CellChat to analyze cell-cell comunication patways, and enrichGO for the gene ontology pathway enrichment analysis. It's a learning repository where I explore how to process, analyze, and visualize scRNA-seq data step by step. This repository is a comprehensive collection of state-of-the art tools in the field on scRNASeq.<br>



## 📂 What’s Inside the repository

\-**Code** folder - containing all the algorith each as module in its own sub-folder.<br> -**Results** folder - containing a series of results and graphs.<br>
